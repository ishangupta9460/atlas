API CHANGES
- POST /commitments -> 201; GET/PATCH /commitments/{id} -> 200.
- JWT owner only; missing/foreign entity or relationship -> indistinguishable 404;
  malformed/forbidden input -> 400; illegal state-dependent mutation -> 409.
- Draft requires neither title nor criterion; both complete establish Ready. After Draft,
  defining fields cannot be cleared. Importance/flexibility must resolve explicitly or from
  Category defaults; no universal fallback. PATCH does not dynamically inherit category changes.
- ownDeadline: explicit-offset ISO input, UTC Instant, truncate microseconds, nullable;
  omission preserves, null clears. No date-only or implicit local timezone input.
- Category API adds nullable defaultImportance; omission preserves, null clears on PATCH.
- No public work-state, progress, scheduling, session, cancellation, delete or collection route.
- Domain execution transition seams enforce required context, write transition events, and do
  not implement progress percentage/report/session orchestration (EXEC-004/EXEC-001 later).
