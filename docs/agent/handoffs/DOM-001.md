## WHAT WAS DONE

- Added the `goals` schema with independently constrained `lifecycle_state` and `planning_state` columns, user FK, and user index.
- Added Goal entity, repository, service, API controller, DTOs, and standard not-found/invalid-state errors.
- Implemented only the documented lifecycle and planning-state transitions. All transition writes create their corresponding generic Event Log entry in the same Spring transaction.
- Extended the Phase 0 `events` table in place to support generic `entity_type`, `entity_id`, `actor`, `reason`, and `payload` fields while preserving task-event compatibility. Existing task event records are backfilled as `entity_type = task`; existing task code remains covered by its tests.
- Added state-machine tests (all documented paths, invalid paths, axis independence, and all event types), transaction rollback coverage, and authenticated API contract/user-isolation coverage.

## DATABASE CHANGES

- Flyway V4 creates `goals` with `user_id` FK, nullable `target_deadline`, and separate checked state columns.
- Flyway V4 promotes `events` from the V3 task-only format to generic event identity. It retains nullable `task_id` and its FK for prior task rows; no existing task rows are deleted or rewritten beyond setting generic identity fields.
- Migration was applied by Flyway against a fresh H2 database in MySQL mode during integration tests. The initial `DROP CHECK` syntax failed in H2; V4 now uses named `DROP CONSTRAINT`, which passed the fresh migration run.

## API CHANGES

- `POST /goals` — creates a Goal.
- `GET /goals/{id}` — reads a caller-owned Goal with both state fields.
- `PATCH /goals/{id}` — updates title and/or deadline only.
- `POST /goals/{id}/pause` — At Risk → Paused.
- `POST /goals/{id}/abandon` — Active lifecycle → Abandoned.
- `POST /goals/{id}/risk-response` — At Risk → Active after user feasibility confirmation.
- All routes take ownership only from the authenticated JWT principal; foreign goals return `404 GOAL_NOT_FOUND`.
- No API-spec document changed: these are the existing §2 routes.
